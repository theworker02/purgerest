# purgerest

Purge HTML/Markdown rest fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/purgerest/

## Install / run

```bash
git clone https://github.com/theworker02/purgerest.git
cd purgerest
node src/cli.js
node --test
```
